GET/locais

Locais próximos

Recebe um CEP e devolve os bancos de leite e postos de coleta mais próximos. A lista é a da Rede Brasileira de Bancos de Leite Humano. A distância usa a coordenada do CEP.

Não tem autenticação. O navegador do site pode chamar direto.

Parâmetros

nometipo
cep string Obrigatório. 8 dígitos, com ou sem hífen. Exemplo: 01310100 ou 01310-100.
limite int Quantos locais voltar. De 1 a 20. Se omitir, volta 5.

Request

GET /locais?cep=01310100&limite=2

Campos

campo
enderecoEndereço resolvido a partir do CEP enviado.
quantidadeQuantos locais vieram em locais.
fonteDe onde saiu a lista de locais.
nomeNome do banco ou posto.
tipoBanco de Leite, Posto de Coleta ou Centro de Referência.
contatoTelefone. Vem null quando o cadastro não tem.
distancia_kmDistância em linha reta, em quilômetros, com uma casa decimal.
distancia_aproximadatrue quando o ponto do local é o da cidade, não o da rua. O CEP daquele cadastro não tinha coordenada.
google_mapsLink para abrir o local no Google Maps.

Testar

a resposta aparece aqui
GET/health

Status

Diz se a API subiu e quantos locais estão carregados.

Request

GET /health

Resposta 200

{
  "status": "ok",
  "locais": 493,
  "com_coordenada": 490,
  "atualizado_em": "2026-10-01T01:08:55+00:00",
  "fonte": "Rede Brasileira de Bancos de Leite Humano (Fiocruz)"
}
locaisTotal de bancos e postos na base.
com_coordenadaQuantos entram no cálculo de distância.
atualizado_emQuando a lista foi gravada, em UTC.

Erros

O corpo é sempre {"detail": "mensagem"}.

status
400CEP inválido. Não tem 8 dígitos.
404CEP não encontrado.
422O CEP existe, mas não tem coordenada para calcular a distância.
502A consulta do CEP falhou.
503A lista de locais não está carregada.
 
{
  "detail": "CEP inválido."
}
